# Contributing to KMP Battery

Contributions are always welcome! Whether it's a bug report, new feature, or documentation
improvement, here is how you can help.

## How to Contribute

1. **Fork the repository:** Click the "Fork" button on GitHub.
2. **Clone the fork:** `git clone https://github.com/your-username/KmpBattery.git`
3. **Create a branch:** `git checkout -b feature/amazing-feature`
4. **Make your changes:** Keep code clean and follow existing conventions.
5. **Commit your changes:** `git commit -m 'Add some amazing feature'`
6. **Push to the branch:** `git push origin feature/amazing-feature`
7. **Open a Pull Request:** Describe your changes clearly.

## Reporting Issues

If you find a bug, please open an issue in the repository. Provide as much detail as possible,
including:

- Platform details (Android/Desktop/iOS/etc.)
- Steps to reproduce.
- Expected vs. actual behavior.

## Code of Conduct

Please be respectful and helpful to all community members.

Thank you for helping us improve this project!
